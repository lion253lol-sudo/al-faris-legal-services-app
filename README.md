# Al Faris Legal Services App

**Mobile App** · Saudi Arabia

A bilingual mobile app connecting clients with verified lawyers, featuring secure authentication, real-time chat, video calls, payment integration, AI legal consultation, and an admin panel for monitoring and analytics.

## Highlights

- Bilingual mobile experience
- Verified lawyers and multi-role access
- Secure authentication
- Real-time chat and video calls
- Payment integration
- AI legal consultation
- Admin panel for monitoring and analytics
